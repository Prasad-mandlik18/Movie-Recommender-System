Developed a content-based Movie Recommender System using Python, Scikit-learn, and NLP techniques.
Implemented CountVectorizer and Cosine Similarity to recommend similar movies based on metadata.
Built an interactive web application using Streamlit for real-time movie recommendations.
Integrated TMDB API to fetch and display movie posters dynamically.

Tech Stack: Python, Pandas, NumPy, Scikit-learn, NLP, Streamlit, TMDB API
